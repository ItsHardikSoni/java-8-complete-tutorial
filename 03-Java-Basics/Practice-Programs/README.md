# Java Basics – Practice Programs

Welcome to the Java Basics Practice Programs section!

This folder contains beginner-friendly Java programming exercises designed to improve logical thinking, problem-solving skills, and understanding of Core Java concepts.

All programs are written using Java 8 and include practical examples.

## Topics Covered

### Beginner Programs
1. Student Details
2. Arithmetic Operations
3. Area Of Rectangle
4. Kilometers To Meters
5. Average Of Five Numbers

### Intermediate Programs
6. Swap Numbers using temp variable
7. Swap Numbers without using temp variable

### Real-World Programs
8. CompoundInterest
9. Fahrenheit To Celsius

## How to Run Java Programs

**Step 1:** Make sure JDK 8 or a compatible JDK is installed.

**Step 2:** Open the terminal in the program's directory.

**Step 3:** Compile the Java file.

```bash
javac HelloWorld.java
```

**Step 4:** Execute the program.

```bash
java HelloWorld
```

## Learning Objectives

- Understand Java syntax and programming fundamentals.
- Practice variables and data types.
- Apply type casting and operators.
- Learn to accept user input using Scanner.
- Improve logical thinking through programming exercises.
- Understand how Java is used in simple real-world applications.
