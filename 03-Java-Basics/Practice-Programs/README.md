## How to Run Java Programs

**Step 1:** Make sure JDK 8 or a compatible JDK is installed.

**Step 2:** Open the terminal in the program's directory.

**Step 3:** Compile the Java file.

```bash
javac 01-StudentDetails.java
```

**Step 4:** Execute the program.

```bash
java StudentDetails
```
