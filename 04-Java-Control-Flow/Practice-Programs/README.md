# Java Control Flow - Practice Programs

This folder contains Java 8 practice programs for learning decision-making and looping statements.

## How to Run

**Step 1:** Make sure JDK 8 or a compatible JDK is installed.

**Step 2:** Open the terminal in this folder.

**Step 3:** Compile and run a program.

```bash
javac 01-EvenOdd.java
java EvenOdd
```
